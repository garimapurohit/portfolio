## Run Locally

### Prerequisites

- Node.js and npm installed.
- Git installed.

### Setup

```bash
git clone https://github.com/garimapurohit/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the local URL printed in your terminal, usually `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```

Vite generates the production build in the `dist/` directory.
